# BOMB STACK — 게임 기획서 v1.2

> **문서 성격:** 정밀 검토와 성장·공급·중계 판정을 반영한 구현 기준안
>
> **개정일:** 2026-10-20
>
> **플랫폼:** Steam / Windows 64비트 / 싱글플레이
>
> **입력:** 키보드와 컨트롤러
>
> **장르:** 테트로미노 배치 퍼즐 × 폭탄 빌드 × 로그라이크
>
> **완성 범위:** 기본 모드 1개 / 5스테이지 / 폭탄 4종·종류별 3레벨 / 보조 유물 6종
>
> **개발 원칙:** 1인 개발, AI 적극 활용, 고정된 개발 기한 없음, 범위를 늘리지 않고 완성

**이 문서의 ‘확정’은 무엇을 구현할지 정했다는 뜻이다. 실제 재미·난도·판매 성과가 검증되었다는 뜻은 아니다.** 보드·점수·시간·스테이지 수치는 아래 값으로 구현하고, 플레이 결과가 나오면 수치부터 조정한다. 기본 메커니즘이나 첫 완성판 범위를 바꾸려면 이유와 변경 내용을 문서에 남긴다.

기존 파일 경로를 유지하며 본문의 버전을 기준으로 한다. [이전 기획 검토](BOMB_STACK_기획_검토.md)는 v0.2~v0.3에 대한 기록이다. **v1.2와 이전 버전·검토가 다르면 이 문서를 구현 기준으로 사용한다.**

이번 검토의 근거·보완 결과·남은 위험은 [2026-10-20 정밀 검토](BOMB_STACK_정밀_검토_2026-10-20.md)에 정리한다.

**이번 수정의 기준:** 새 폭탄 획득·폭탄 강화·공통 강화·유물은 모두 해당 판에서만 적용한다. 새 판은 같은 기본 조건으로 시작하며 영구 해금·영구 구매·누적 성능 강화는 없다. 사용자가 선택한 성장 방식은 ‘경험치를 얻어 레벨업마다 3개 중 선택’이다. 일반 블록 파괴가 주 경험치이고, v1.2에서는 점수 목표 달성과 성장 기회의 충돌을 줄이기 위해 중간 스테이지 완료 XP를 보조로 추가한다. 폭탄 종류·레벨별 범위·경험치 곡선은 초기 설계값이며 플레이 검증 전이다. 이번 사용자 답변은 ‘계획해서 큰 연쇄를 만들되 후반에는 확실히 강해짐’, ‘범위 차이와 소수의 독특한 작동 방식’이다.

## 1. 방향과 완성 목표

### 1.1. 한 줄 소개

테트로미노로 폭탄과 트리거를 배치하고, 서로 다른 폭탄의 폭발과 셀별 낙하를 연결하는 퍼즐 로그라이크다. 한 판 안에서 경험치를 얻어 새 폭탄을 획득하고 강화하며, 판이 끝나면 빌드는 초기화된다. 줄을 채워도 지워지지 않는다.

### 1.2. 핵심 경험

1. **배치:** 다음 조각과 폭탄 종류를 보고 공간 확보와 폭탄 연결을 준비한다.
2. **점화:** 트리거 접촉으로 서로 다른 범위의 폭탄을 연결한다.
3. **낙하:** 폭발 후 남은 셀이 떨어져 새 접촉과 다음 폭발 묶음을 만든다.
4. **성장:** 파괴한 일반 셀로 경험치를 얻고, 레벨업마다 제시되는 3개 중 새 폭탄 또는 강화를 선택한다.
5. **빌드:** 이번 판의 폭탄 구성·종류별 레벨·보조 유물에 맞춰 배치를 바꾼다.
6. **재도전:** 승리·패배 후에는 기본 폭탄부터 다시 시작하고 다른 선택을 시도한다.

별도 지지대·기둥·구조물은 없다. 일반 블록을 제거한 뒤 남은 셀이 아래로 이동하는 **폭발 후 셀별 중력**만 사용한다. 이하에서 ‘아래 블록 제거’와 ‘셀 낙하’로 표현한다.

### 1.3. 대상과 플레이 길이

- 낮은 시간 압박에서 블록 조작·공간 배치·폭탄 조합을 함께 즐기는 PC 이용자를 대상으로 한다.
- 자동 낙하는 유지하되 스테이지별 속도 상승은 없다. 압박은 보드 공간·남은 조각·목표 점수에서 만든다.
- 후반 성장도 배치와 점화 판단을 남긴다. 보드 대부분을 조건 없이 지우는 것을 기본 성장 목표로 삼지 않는다. 독특한 작동 방식은 중계 폭탄 1종부터 시험한다.
- 1회 플레이 목표는 10~20분이다. 레벨업 선택이 추가되므로 실제 소요 시간을 다시 확인한다.
- 한 판 안의 선택과 시드 차이가 반복 동기다. 반복 플레이로 시작 능력치를 높이는 파밍을 요구하지 않는다.
- 폭탄 종류가 늘었다는 이유만으로 재미·반복성이 생겼다고 판단하지 않는다. 종류·강화 선택에 따라 배치가 달라져야 한다.
- Steam·Windows·키보드와 컨트롤러·5스테이지·보조 유물 6종은 유지한다. 구체적인 개발 기한은 두지 않는다.

### 1.4. 첫 완성판에서 제외하는 기능

영구 해금, 판 밖 재화·상점·성능 강화, 판 안 상점, Hold, 수동 기폭, 수동 셀 변환, 분기 지도, 보스, 상태이상·지속 피해, 온라인 기능, 일일 도전, 무한 모드, 별도 난이도 모드, 도전과제, Steam Cloud, 실행 중 저장·이어하기는 제외한다.

이번에는 사용자가 선택한 경험치·레벨업 방식으로 성장시킨다. 구매·가격 경제는 함께 넣지 않는다. 출시 정가·상점 문구·공개 일정은 판매 준비에서 별도 결정한다.

## 2. 한 판의 흐름

### 2.1. 전체 진행

```text
새 게임: 빈 보드 / 기본 폭탄 Lv.1 / 플레이어 Lv.1 / 유물 없음
                           ↓
             배치 → 폭발 → 셀별 낙하 → 연쇄 종료
                           ↓
                   점수와 경험치 정산
                           ↓
          종료 판정 ── 승리·패배 → 빌드 종료
                           ↓ 계속
             레벨업이 있으면 3개 중 1개 선택
                           ↓
     중간 스테이지 목표 달성 시 보조 유물 3개 중 1개 선택
                           ↓
            보드·빌드 유지 → 다음 배치·스테이지
                           ↓
                   5스테이지 완료 → 승리
```

- 매 판 기본 폭탄만 보유한 동일한 조건으로 시작한다. 다른 폭탄 3종은 처음부터 해당 판의 획득 후보에 들어 있다.
- 플레이어 레벨·경험치·보유 폭탄 종류·폭탄 레벨·공통 강화·유물은 스테이지 사이에는 유지하고 새 판에서는 전부 초기화한다.
- 1~4스테이지 완료 시 유물 선택 4회는 유지한다. 레벨업 선택은 별도의 경험치 성장이다.
- 새 게임·다시 시작은 새 시드로 1스테이지를 시작한다. 결과 화면 재시작에는 추가 확인을 넣지 않는다.
- 설정·안내 확인·최고 기록만 판 밖에 보존한다. 기록을 저장해도 다음 판의 성능과 선택 후보는 바뀌지 않는다.

### 2.2. 배치 한 번의 흐름

```text
조각 생성 → 이동·회전·낙하 → 조각 고정
                                 ↓
                폭탄별 범위로 접촉 점화·전달
                                 ↓
                    제거 → 열별 셀 중력
                                 ↓
                재접촉 시 다음 폭발 묶음 반복
                                 ↓
             점수·경험치 → 종료 판정 → 성장 선택
                                 ↓
                     다음 조각·스테이지
```

한 조각 고정부터 모든 폭발·낙하가 끝날 때까지가 한 배치다. 레벨업이나 유물 선택으로 처리 중인 폭발의 성능을 바꾸지 않는다.

## 3. 보드와 셀

### 3.1. 보드

| 항목 | 확정 규칙 |
|---|---|
| 크기 | 가로 10칸 × 세로 18칸 |
| 좌표 | 왼쪽 아래가 (0,0), 오른쪽 위가 (9,17) |
| 시작 상태 | 모든 셀이 빈칸 |
| 경계 | 좌우·바닥·상단 밖으로 이동하거나 고정할 수 없음 |
| 숨겨진 행 | 사용하지 않음 |
| 줄 완성 | 삭제·점화·추가 점수 없음 |
| 중력 방향 | 아래쪽만. 좌우 이동이나 물리 회전 없음 |

활성 조각은 고정 전까지 보드 셀과 구분한다. 충돌과 착지 판정에는 고정된 셀만 사용한다.

### 3.2. 셀 종류

| 표기 | 이름 | 기본 역할 | 기본 폭발에 포함되면 |
|---|---|---|---|
| N | 일반 | 공간 점유·기본 점수·경험치 대상 | 제거 |
| B | 폭탄 | 종류별 범위로 발동, 다른 종류의 B에도 전달 | 폭발하고 제거 |
| T | 트리거 | 인접 폭탄을 점화 | 제거. 자체 폭발 없음 |
| . | 빈칸 | 셀 없음 | 변화 없음 |

- 조각 하나는 4셀로 이루어진다.
- 한 조각에는 B 또는 T가 **최대 1개** 들어간다. 나머지는 N이다.
- 같은 조각 안의 B·T가 서로 붙어 즉시 점화되는 경우는 없다.
- 트리거는 점화 신호를 준다는 이유만으로 소모하지 않는다. 실제 폭발 범위에 포함될 때 제거한다. 가로 폭탄의 위쪽에 닿은 T처럼 해당 범위 밖에서 점화한 T는 기본 규칙에서도 남을 수 있다.
- ‘내열 트리거’ 유물을 보유하면 T의 파괴 규칙만 예외가 생긴다. 중력과 점화 규칙은 유지한다.

### 3.3. 기본 폭발 범위

아래는 **B01 기본 폭탄 Lv.1**의 범위다. 좌표 (x,y)에서 가로·세로 각각 중심으로부터 1칸, 총 **3×3**이다. 다른 종류·레벨은 3.4의 개별 범위를 사용한다.

```text
X X X
X B X
X X X
```

- 보드 밖은 무시한다.
- 빈칸에는 파괴 점수를 주지 않는다.
- 범위에 들어간 다른 폭탄도 발동한다.
- 같은 폭발 묶음에서 같은 셀은 한 번만 제거·집계한다.
- 폭탄과 트리거의 파괴 자체는 기본 점수를 주지 않는다.

### 3.4. 폭탄 4종과 종류별 강화

다음 표는 정밀 검토 후 첫 비교에 사용할 성능 기준값이다. 종류 수 4종은 이번 수정에서 채택한 최소 구성안이며, 종류별 제거 효율과 레벨별 범위는 아직 밸런스 검증 전이다.

| ID | 종류 | Lv.1 | Lv.2 | Lv.3 | 배치 역할 |
|---|---|---|---|---|---|
| B01 | 기본 폭탄 | 3×3, 최대 9칸 | 3×3 + 상하좌우 거리 2 끝점, 최대 13칸 | Lv.2 + 상하좌우 거리 3 끝점, 최대 17칸 | 주변 정리와 단계적 범위 성장 |
| B02 | 가로 폭탄 | 가로 7×세로 1 | 가로 9×세로 1 | 가로 11×세로 1 | 멀리 떨어진 B의 수평 연결 |
| B03 | 세로 폭탄 | 가로 1×세로 7 | 가로 1×세로 9 | 가로 1×세로 11 | 같은 열의 블록 제거·낙하 준비 |
| B04 | 중계 폭탄 | 파괴 3×3 / 중계 거리 3 | 파괴 3×3 / 중계 거리 4 | 파괴 3×3 / 중계 거리 5 | 중간 블록을 남기며 먼 B 점화 |

- 직사각형은 B 중심에 배치한다. 예를 들어 가로 7칸은 x±3, y는 동일하다. 보드 밖은 무시한다.
- 기본 폭탄 Lv.2는 3×3에 (±2,0),(0,±2)를 더한다. Lv.3은 여기에 (±3,0),(0,±3)를 더한다. 대각선 바깥 칸을 모두 채우는 5×5·7×7로 해석하지 않는다.
- 중계 폭탄의 파괴 범위는 모든 레벨에서 3×3이다. 중계는 같은 행·열에서 지정 거리 안의 **다른 B만 점화**한다. 사이에 N/T가 있어도 중계는 통과하며, 중계 선만으로 N/T를 파괴하지 않는다. 대각선으로 중계하지 않는다.
- 가로 폭탄 Lv.3의 명목 범위는 11칸이지만 보드 너비가 10이므로 유효 셀 수는 최대 10이다. 보드 경계와 밀집도를 고려해 효율을 비교한다.
- 모든 B는 파괴 범위 안의 다른 B에 전달한다. 중계 폭탄은 별도로 중계 범위의 B도 발동시킨다. 대상은 **자기 종류·현재 레벨의 파괴/중계 규칙**을 사용한다.
- 조각 회전은 특수 셀 위치를 바꾸지만 폭탄 범위의 방향은 바꾸지 않는다. 가로 폭탄은 항상 보드 가로 방향이다.
- 모든 종류는 같은 T 접촉 규칙을 사용한다. 종류별 퓨즈 시간·별도 기폭 조건·지속 피해는 없다.
- 종류별 강화는 최대 Lv.3이다. 첫 구성에서는 기본 폭탄도 5×5 전체 파괴로 키우지 않는다. 전역 범위 증가 유물로 모든 종류를 같게 만들지 않는다.
- 가로·세로 폭탄은 멀리 연결하는 대신 국소 제거량이 적을 수 있다. 기존 목표 점수와 생성 비율이 그대로 적절하다고 가정하지 않는다.

### 3.5. 판 안의 폭탄 보유

- 시작은 B01 Lv.1이다.
- 한 판에 **기본 폭탄을 포함해 최대 3종**을 보유하는 초기 구성으로 정한다. 나머지 종류를 포기하는 선택이 빌드 차이를 만든다.
- 신규 폭탄 선택은 해당 종류 Lv.1을 이번 판 공급 후보에 넣는다. 보드에 폭탄을 공짜로 즉시 생성하지 않는다.
- 같은 종류의 레벨은 해당 판에서 공유한다. 기존 보드·활성 조각·미리 보기의 해당 종류에도 적용하며 UI 범위를 갱신한다.
- 강화 선택 자체로 기존 보드를 폭발시키지 않는다. 다음 조각 고정 이후 검사·폭발에서 새 성능을 적용한다.
- 신규 종류는 기존 강한 종류의 공급 비중을 낮추는 교환을 포함한다. 선택 화면에 현재→획득 후 종류 비중과 실제 레벨을 보여 주고, 강제 획득하지 않도록 공통 강화 선택지를 항상 둔다. 신규 획득이 항상 더 강하다고 보장하지 않는다.
- 새 판에서는 보유 종류·레벨을 B01 Lv.1로 되돌린다. 이전 판에서 획득한 종류를 영구 해금하지 않는다.

## 4. 조각 형태·회전·생성 위치

### 4.1. 기본 형태 7종

I, O, T, S, Z, J, L을 사용한다. 아래 도형은 4×4 로컬 좌표의 초기 방향이다. 표는 위쪽 행부터 읽으며 로컬 좌표는 왼쪽 아래 (0,0)부터 시작한다.

| 형태 | 위→아래 4개 행 | 회전 중심 |
|---|---|---|
| I | `.... / IIII / .... / ....` | (1.5,1.5) |
| O | `.... / .OO. / .OO. / ....` | (1.5,1.5) |
| T | `.T.. / TTT. / .... / ....` | (1,2) |
| S | `.SS. / SS.. / .... / ....` | (1,2) |
| Z | `ZZ.. / .ZZ. / .... / ....` | (1,2) |
| J | `J... / JJJ. / .... / ....` | (1,2) |
| L | `..L. / LLL. / .... / ....` | (1,2) |

- 최초 방향은 항상 위 표와 같다.
- 90도 시계·반시계 회전을 제공한다. 180도 전용 버튼은 넣지 않는다.
- 특수 셀은 원래 셀의 속성이므로 회전과 함께 위치가 바뀐다.
- O는 차지하는 네 칸이 같아도 **특수 셀의 위치는 회전**한다. 회전 입력을 무시하지 않는다.
- 회전 전후 셀 좌표는 정수 격자에 놓여야 한다.

### 4.2. 회전 보정

회전 결과가 겹치거나 보드 밖이면 아래 오프셋을 순서대로 적용한다. 첫 유효 위치를 채택하고, 모두 실패하면 회전을 취소한다.

1. (0,0)
2. (-1,0)
3. (+1,0)
4. (-2,0)
5. (+2,0)
6. (0,+1)
7. (0,+2)

이는 본작의 고정된 단순 보정 규칙이며 표준 테트리스 회전 규칙과 동일하다고 가정하지 않는다. 회전 보정으로 아래쪽 이동은 하지 않는다. 성공한 회전도 고정 지연을 초기화하지 않는다.

### 4.3. 생성 위치와 충돌

- 모든 조각은 초기 방향으로 **로컬 원점 (3,14)**에서 생성한다. 공통 4×4 생성 틀은 보드 x=3~6, y=14~17이다.
- I는 x=3~6, y=16에 놓인다. O는 x=4~5, y=15~16에 놓인다. 다른 형태는 주로 x=3~5, y=16~17을 사용한다.
- 빈 보드에서는 I를 포함한 모든 조각을 생성 직후 회전할 수 있다. 조각 위쪽의 로컬 빈칸도 포함해 생성 틀을 두므로 상단 경계를 넘는 회전을 강요하지 않는다.
- 생성된 네 셀 중 하나라도 기존 셀과 겹치면 **생성 불가 패배**다.
- 생성 충돌을 피해 좌우로 자동 이동시키지 않는다.
- 스테이지를 넘겨도 다음 조각의 형태·특수 셀·순서를 다시 추첨하지 않는다.

## 5. 생성 규칙과 미리 보기

### 5.1. 형태 Bag

7종 형태를 하나씩 넣고 균등하게 섞어 순서대로 소비한다. 모두 소비한 뒤 다음 Bag을 섞는다. 스테이지 전환 때 초기화하지 않는다.

### 5.2. 속성 Bag

기존 10조각 Bag 대신 **4조각 Bag `B, B, T, N`**을 사용한다.

| 조각 속성 | 한 Bag의 수량 | 평균 비중 |
|---|---:|---:|
| 폭탄 조각 | 2 | 50% |
| 트리거 조각 | 1 | 25% |
| 일반 조각 | 1 | 25% |

- 각 Bag을 균등하게 섞는다. 형태 Bag과 독립적으로 진행한다.
- 인접한 Bag 경계를 포함해 **트리거 미등장 최대 6조각**, **폭탄 미등장 최대 4조각**, **일반 조각 연속 최대 2조각**이다.
- 시작 Bag에서 트리거가 처음 나오기 전에는 최대 3조각을 배치할 수 있다.
- B01 Lv.1만 공급되는 시작 상태에서 4조각은 16셀을 추가하고 폭탄 2개의 범위 합은 최대 18칸이다. 공급량만으로 제거량이 반드시 부족한 구조는 피하되, 실제 제거량은 빈칸·경계·범위 중첩에 따라 줄어든다.
- 이 제거량 비교는 시작 폭탄 기준이다. 종류 획득·레벨 상승 후에는 범위와 실제 제거량이 달라지므로 빌드별로 다시 측정한다.
- 공백 상한은 공급 빈도의 보장이며 공정한 난도나 생존 가능성의 증명이 아니다.
- 이번 버전에는 추가 확률 보정·긴급 지급·속성 재추첨을 넣지 않는다.

### 5.3. 특수 셀 위치

- B/T 조각이면 초기 방향의 4개 셀 중 하나를 동일 확률로 선택한다.
- 셀의 속성은 회전해도 유지한다.
- 일반 조각은 4개 모두 N이다.
- 폭탄 조각이면 특수 셀 위치와 별도로 5.5의 폭탄 종류를 배정한다. 유물·레벨업은 형태 Bag과 B/B/T/N 속성 비율을 변경하지 않는다.

### 5.4. 다음 조각 정보와 시드

- 활성 조각 외에 **다음 조각 3개**를 표시한다.
- 형태·B/T 종류·특수 셀 위치를 보여 주고, B이면 폭탄 세부 종류와 현재 레벨도 보여 준다.
- 생성 정보는 미리 정해 두고, 고정할 때마다 대기열에서 하나를 사용하고 뒤에 하나를 추가한다.
- 보드·Bag 진행·대기열은 스테이지 사이에 유지한다.
- 형태·속성·특수 셀 위치·폭탄 종류·레벨업 후보·유물 후보는 재현 가능한 별도 난수 흐름으로 관리한다. 보상 추첨이 형태·속성 순서를 바꾸지 않게 한다.
- 같은 게임 버전·시드·선택·배치 입력은 같은 판정 결과를 내야 한다. 버전 간 동일 시드 호환은 보장 범위에서 제외한다.
- 시드 입력 UI는 첫 완성판에 넣지 않는다. 시드와 배치 기록은 개발 중 오류 재현에 사용한다.


### 5.5. 보유 종류를 공급에 반영하는 방법

- 평상시 종류 Bag에는 보유한 종류를 각각 1개씩 넣어 섞고 소비한다. 모두 소비하면 다시 채운다. 가중치·종류 판매·편성 화면은 없다.
- 신규 획득 때 남은 종류 Bag을 새 목록으로 재구성한다. 별도로 아래 **첫 등장 보장**을 1회 적용한다.
- 기본 폭탄 1종이면 평상시 비중 100%, 2종이면 각 50%, 3종이면 각 1/3이다. 첫 등장 보장 때문에 짧은 구간의 실제 비중은 다를 수 있다.
- 종류별 강화는 Bag을 초기화하지 않는다. 스테이지 사이에는 남은 Bag과 미소비 첫 등장 보장을 유지한다.

**첫 등장 보장**

1. 새 종류를 획득하면 그 종류의 보장 항목을 FIFO로 추가한다. 항목은 ‘미배정’ 또는 ‘특정 대기열 조각에 배정됨’을 구분한다.
2. 미배정 항목을 앞에서부터 처리한다. 다음 3개 중 아직 예약되지 않은 가장 앞 B 조각을 찾아 **세부 종류만** 바꾸고 두 항목을 연결한다. 모양·B/T/N 속성·특수 셀 위치는 유지한다. 이미 배정된 보장 항목을 다른 조각에 중복 배정하지 않는다.
3. 적합한 미리 보기 B가 없으면 이후 생성하는 첫 B에 가장 앞의 미배정 종류를 배정한다. 이 B는 일반 종류 Bag에서 뽑지 않는다. 미리 보기에서 바뀐 원래 종류를 Bag에 되돌려 넣지도 않는다.
4. 같은 배치에서 여러 종류를 획득하면 예약을 덮어쓰지 않고 앞서 얻은 종류부터 서로 다른 B에 배정한다.
5. 바뀐 미리 보기에는 신규 심볼을 강조하고 ‘새 폭탄 첫 등장’을 표시한다. 플레이어의 획득 선택에 따른 공개된 변경이며 숨겨진 재추첨이 아니다.
6. 예약된 B를 실제 생성하면 해당 예약을 완료 처리한다. 새 판에서는 예약도 초기화한다.

- 기존 보드·이미 조작 중인 활성 조각의 종류는 바꾸지 않는다. 레벨업 시에는 다음 조각 생성 전이므로 활성 조각이 없다.
- 기존 미리 보기 종류 유지 원칙의 예외는 이 첫 등장 보장뿐이다. 강화·유물·단순 스테이지 전환은 종류를 다시 뽑지 않는다.
- 기존 속성 Bag의 B 공백 상한은 유지된다. 계속 진행할 수 있는 조건에서 신규 1종은 다음 B, 최대 5배치 이내에 생성된다. 같은 배치에서 2종을 획득하면 두 번째는 그다음 B, 최대 6배치 이내다. 기존 3개 미리 보기까지 포함한 속성 순서 기준이다.
- 승리·패배가 먼저 오면 사용 기회까지 보장하지 않는다. 마지막 스테이지에서 사용하지 못한 신규 획득이 반복되는지는 16.4에서 따로 확인한다.

## 6. 조작과 시간

### 6.1. 게임 중 입력

컨트롤러 표기는 기기의 인쇄 문자 대신 물리 위치를 기준으로 한다.

| 행동 | 키보드 | 컨트롤러 |
|---|---|---|
| 왼쪽·오른쪽 | ←/→ 또는 A/D | D패드 좌/우 |
| 시계 회전 | ↑ 또는 X | 아래쪽 페이스 버튼 |
| 반시계 회전 | Z | 왼쪽 페이스 버튼 |
| 소프트 드롭 | ↓ 또는 S 누르기 | D패드 아래 누르기 |
| 하드 드롭·즉시 고정 | Space 새로 누르기 | 오른쪽 숄더 버튼 새로 누르기 |
| 일시정지 | Esc | 메뉴/시작 버튼 |

- 컨트롤러 스틱으로 조각을 움직이는 기능은 넣지 않는다. D패드로 전체 게임과 메뉴를 조작할 수 있어야 한다.
- 마우스는 메뉴 버튼과 레벨업·유물 선택에 사용할 수 있다. 조각 배치는 키보드·컨트롤러로 한다.
- 좌우 방향을 동시에 누르면 가장 최근에 누른 방향을 적용한다. 그 방향을 놓고 반대 방향이 남아 있으면 남은 방향을 새 입력처럼 적용한다.
- 회전·하드 드롭은 누른 순간 한 번만 적용한다. 양방향 회전을 동시에 누르면 가장 최근 방향을 사용하고, 시점까지 같으면 시계 회전 한 번만 적용한다.
- 같은 처리 시점의 입력 우선순위는 **일시정지 → 하드 드롭 → 회전 → 좌우 이동 → 낙하**다. 하드 드롭으로 고정되면 나머지 조작은 버린다.

### 6.2. 이동·낙하·고정 시간

| 항목 | 구현 기준값 |
|---|---:|
| 자동 낙하 | 1.0초마다 아래 1칸 |
| 스테이지별 가속 | 없음 |
| 소프트 드롭 | 0.05초마다 아래 1칸 |
| 좌우 최초 입력 | 즉시 1칸 |
| 좌우 자동 반복 시작 | 0.15초 유지 후 |
| 좌우 반복 간격 | 0.05초 |
| 지면 접촉 후 고정 지연 | 0.8초 |
| 하드 드롭 | 최저 유효 위치로 즉시 이동·고정 |
| 낙하 점수 | 소프트·하드 드롭 모두 없음 |

- 소프트 드롭 중에는 자동 낙하 주기를 별도로 더하지 않는다. 소프트 드롭을 놓으면 자동 낙하 주기를 새로 시작한다.
- 처음 아래로 이동할 수 없게 된 순간 0.8초 고정 타이머를 시작한다.
- 이후 이동·회전·잠깐의 공중 이동으로 타이머를 초기화하지 않는다. 타이머는 계속 흐른다.
- 타이머가 만료됐을 때 접지 중이면 즉시 고정한다. 공중이면 떨어질 때까지 진행하고 다시 접지하는 순간 고정한다. 공중에서 떠 있는 채로 고정하지 않는다.
- 새 조각은 낙하·고정 타이머를 새로 시작한다.
- 일시정지 중에는 모든 게임 타이머와 진행 중 연출이 정지한다.

### 6.3. 고스트와 입력 잠금

- 현재 방향에서 바로 하드 드롭했을 때의 네 셀 위치를 고스트로 표시한다.
- 고스트 안의 B/T 위치도 표시한다.
- 고정 뒤 폭발·중력·점수 정산 중에는 조작을 받지 않는다.
- 잠금 중 입력을 다음 조각에 예약하지 않는다.
- 연출 종료·레벨업 및 유물 선택 종료·일시정지 해제 뒤에는 눌린 게임 조작을 해제한 후 새 입력을 받아야 한다. 드롭 유지로 다음 조각이 즉시 고정되면 안 된다.
- 앱 포커스를 잃거나 사용 중 컨트롤러가 연결 해제되면 일시정지한다. 키보드로도 재개하거나 메뉴로 돌아갈 수 있다.

### 6.4. 메뉴 입력

| 행동 | 키보드 | 컨트롤러 |
|---|---|---|
| 항목 이동 | 방향키 | D패드 |
| 선택·확인 | Enter | 아래쪽 페이스 버튼 |
| 뒤로 | Esc | 오른쪽 페이스 버튼 |

레벨업·유물 화면에서는 항목 이동만으로 획득하지 않는다. 확인 입력 한 번으로 획득하며 추가 확인창은 띄우지 않는다. 화면을 연 입력이 확인으로 이어지지 않게 이전 입력을 소모한다. 입력 장치가 바뀌면 버튼 안내도 바꾼다.

## 7. 점화·폭발·중력 판정

### 7.1. 용어

- **배치:** 한 조각 고정에서 모든 연쇄가 끝날 때까지.
- **폭발 묶음:** 중력 적용 전, 접촉 점화와 폭탄 간 전달로 함께 확정한 폭탄 전체.
- **묶음 수:** 한 배치에서 실제 폭탄이 발동한 묶음의 수. 빈 검사나 단순 낙하를 세지 않는다.
- **중력 연쇄:** 첫 묶음 제거·중력 후 재접촉으로 두 번째 이상 묶음이 발생하는 것.

폭탄 4개가 중력 전에 모두 전달되어 터지면 **폭탄 4개 / 묶음 1회**다. 폭탄이 하나씩 두 번의 중력 전후에 터지면 **폭탄 2개 / 묶음 2회**다.

### 7.2. 한 묶음의 처리

1. 활성 조각의 4셀을 보드에 고정하고 남은 조각 수를 1 줄인다.
2. T와 상하좌우로 접촉한 B를 **보드 전체에서** 모두 찾는다.
3. 각 B의 **파괴 범위**에 든 B를 추가한다. B04이면 **중계 범위**에 든 B도 추가한다. 추가된 B도 자기 종류·레벨의 규칙으로 탐색하고 더 추가할 B가 없을 때까지 반복한다.
4. 발동 B를 먼저 확정하고, 발동한 B들의 **파괴 범위만** 합쳐 제거 대상을 만든다. 중계 선 위의 N/T를 제거 대상에 넣지 않는다.
5. 실제 제거되는 N 수·전체 셀 수를 집계하고 대상을 동시에 제거한다.
6. 폭발 위치와 무관하게 **보드 전체의 모든 열**을 압축한다. 각 열의 상대적인 위아래 순서는 유지한다. 폭발과 떨어진 열의 기존 빈 공간도 메워질 수 있다.
7. 중력이 모두 끝난 보드에서 다시 T–B 접촉을 검사한다.
8. 점화 B가 있으면 다음 묶음으로 3~7을 반복한다. 없으면 배치를 정산한다.

첫 검사에서 발동 B가 없으면 **폭발도 전체 보드 중력도 적용하지 않는다.** 일반 조각의 빈 공간은 폭발 전까지 유지한다.

### 7.3. 동시성과 예외

- 한 T에 여러 B가 닿아 있으면 해당 B를 모두 최초 점화 대상으로 확정한다.
- T를 먼저 지워 일부 B의 점화를 누락시키지 않는다.
- 처리 중 겹친 범위의 B는 한 번만 발동하고 같은 묶음의 N은 한 번만 집계한다.
- 좌표 중복 제거는 **묶음 내부**에서만 한다. 중력 뒤 같은 좌표에 내려온 다른 셀은 새 파괴 대상이다.
- 중력 이동 도중 스쳐 지나가는 T–B 접촉은 검사하지 않는다. 모두 착지한 뒤 검사한다.
- 폭발은 중력을 적용하기 전의 보드 좌표로 계산한다. 전달 연출 도중 셀 좌표를 변경하지 않는다.
- 점화 증폭기를 보유하면 최초·후속 검사 모두 대각선 접촉도 인정한다.
- 같은 묶음에 서로 다른 폭탄이 있으면 각자의 파괴 범위를 합친다. 중계는 점화 연결로만 기록한다. 최초 B의 범위를 다른 B에 복사하지 않는다.
- 중계와 폭발로 같은 B를 여러 번 발견해도 한 번만 발동한다. 중계끼리 서로를 가리켜도 무한 재발동하지 않는다.
- 중계로 발동한 B는 같은 묶음에 포함한다. 중계 선의 길이만큼 묶음 수를 늘리거나 중간에 중력을 적용하지 않는다.
- 현재 배치의 범위·성능은 고정 시점의 성장 상태로 계산한다. 레벨업·보상은 배치 정산 후 처리한다.
- 내열 트리거를 보유하면 범위에 든 T는 남기고 다른 파괴 대상을 제거한다. 남은 T도 중력으로 낙하한다.
- 모든 묶음은 최소 1개의 B를 제거한다. 처리 중 B를 생성하지 않으므로 같은 배치가 무한 연쇄할 수 없다.

## 8. 점수와 경험치

### 8.1. 배치 집계

| 기호 | 의미 |
|---|---|
| n | 이번 배치에서 실제 제거된 일반 셀 수 |
| b | 종류와 관계없이 발동한 폭탄 총수 |
| w | 실제 폭발 묶음 수 |
| a | 회수 숙련 획득 횟수 |
| d | 낙하 숙련 획득 횟수 |
| e | 폭탄 숙련 획득 횟수 |
| r01·r02·r04·r05 | 해당 유물 보유 시 1, 미보유 시 0 |

폭발이 없으면 점수·경험치는 0이다. 폭발이 있으면 다음과 같이 배치 전체를 한 번 정산한다.

```text
일반 셀 단가 u = 10 + a + 2 × r01
기본 배율 m = min(3.0, 1.0 + 0.5 × (b - 1))
최종 배율 = m + (b ≥ 2일 때 0.5 × r02, 아니면 0)

파괴 점수 = floor(n × u × 최종 배율)
중력 보너스 = max(0, w - 1) × (30 + 5 × d + 30 × r04)
폭탄 보너스 = b × 5 × e
대량 파괴 보너스 = n ≥ 10일 때 75 × r05, 아니면 0
배치 점수 = 파괴 점수 + 중력 보너스 + 폭탄 보너스 + 대량 파괴 보너스

일반 셀 경험치 = n
중간 스테이지 완료 경험치 = 진행 가능한 1~4스테이지 완료 시 10 XP
총 획득 경험치 = 일반 셀 경험치 + 해당 완료 경험치
```

- 회수·낙하·폭탄 숙련은 10.3의 공통 강화다. 레벨업마다 최소 1개를 제시한다.
- 단가가 홀수가 되면 0.5점이 생길 수 있다. **파괴 점수 전체에서 한 번 버림**하고 나머지 정수 보너스를 더한다. 묶음별 버림은 하지 않는다.
- 정수 구현은 2배 배율로 파괴 점수를 구한 뒤 2로 나눈다.
- 일반 셀 XP는 N 하나당 1이다. 배율·유물·드롭·폭탄 수로 증폭하지 않는다.
- 중간 스테이지 완료 XP 10은 목표를 적은 파괴량으로 넘긴 판에도 성장 기회를 보조하기 위한 초기값이다. 9.3의 진행 가능 판정 후 한 번만 지급한다. 최종 승리·패배에는 추가 완료 XP나 성장 화면이 없다.
- 다른 묶음에서 같은 좌표의 새 N을 제거했다면 새 점수·경험치로 센다.
- 빈칸·B·T·줄 완성·드롭 거리에는 경험치가 없다.
- n=0, w≥2라면 중력 점수는 받을 수 있지만 일반 셀 XP는 0이다. 이 배치로 진행 가능한 중간 목표를 달성했다면 별도 완료 XP 10은 받을 수 있다.

### 8.2. 계산 예시

아래 XP는 중간 스테이지 완료 보너스가 없는 배치 기준이다. 완료 배치이면 해당 조건에 따라 10 XP를 더한다.

| 배치 결과 | 성장 상태 | 점수 / 경험치 |
|---|---|---|
| n=6, b=2, w=1 | 강화·유물 없음 | 90점 / 6 XP |
| n=6, b=2, w=2 | 강화·유물 없음 | 120점 / 6 XP |
| n=10, b=3, w=2 | 연쇄 증폭기+낙하 충전기+폭파 보너스 | 385점 / 10 XP |
| n=8, b=2, w=2 | 정밀 폭파만 | 174점 / 8 XP |
| n=1, b=2, w=1 | 회수 숙련 1회 | floor(1×11×1.5)=16점 / 1 XP |

스테이지 점수와 총점에는 같은 배치 점수를 더한다. 경험치는 별도 누적하고 스테이지 전환으로 초기화하지 않는다. 폭탄별 레벨은 파괴 범위를 바꾸며 별도의 종류별 점수 계수를 추가하지 않는다.

## 9. 스테이지·승리·패배

### 9.1. 스테이지 표

5스테이지 모두 같은 보드를 사용한다. 조각 제한은 동일하게 두고 목표 점수만 올려 폭탄 빌드·보조 유물·배치 효율을 요구한다.

| 스테이지 | 해당 스테이지 목표 점수 | 최대 사용 조각 | 완료 보상 |
|---|---:|---:|---|
| 1 | 200 | 20 | 유물 1개 선택 |
| 2 | 350 | 20 | 유물 1개 선택 |
| 3 | 500 | 20 | 유물 1개 선택 |
| 4 | 650 | 20 | 유물 1개 선택 |
| 5 | 800 | 20 | 승리 |

이 표는 **v1.0에서 유지하는 비교용 초기값**이다. 다양한 폭탄과 판내 레벨업이 추가되었으므로 같은 수치로 적정 난도라고 확정하지 않는다. 전체 빌드를 연결한 뒤 목표 점수부터 다시 조정한다. 조각 제한·종류별 범위·경험치·유물 효과를 한꺼번에 바꾸지 않는다.

### 9.2. 계승과 초기화

| 항목 | 다음 스테이지 처리 |
|---|---|
| 보드 셀·배치 | 유지 |
| 보유 폭탄·종류별 레벨 | 유지 |
| 플레이어 레벨·경험치·공통 강화 | 유지 |
| 보유 유물 | 유지, 새로 고른 유물 추가 |
| 형태·속성·폭탄 종류 Bag 진행 | 유지 |
| 다음 조각 3개와 특수 셀 위치 | 유지 |
| 총점·최대 폭탄 수·최대 묶음 수 | 유지 |
| 스테이지 점수 | 0으로 초기화 |
| 남은 조각 | 20으로 초기화 |
| 사용하지 않은 조각 수 | 이월하지 않음 |
| 목표를 넘긴 점수 | 다음 목표에 이월하지 않음. 총점에는 모두 반영 |

- 목표를 넘긴 배치도 연쇄를 끝까지 처리한다.
- 목표 달성 이후 추가 조각을 배치해 보드를 정리할 수 없다.
- 레벨업·유물 선택 중에는 보드를 그대로 볼 수 있고 설명을 읽을 수 있다.
- 새 폭탄·강화·유물을 고르는 순간 기존 보드를 다시 점화·낙하시키지 않는다. 새 규칙은 다음 고정부터 적용한다. 새로운 종류의 공급 시점은 5.5를 따른다.

### 9.3. 정확한 종료 우선순위

한 배치의 모든 묶음·중력·점수·경험치를 집계한 뒤 다음 순서로 판정한다.

1. **5스테이지 목표 달성:** 승리한다. 다음 생성 검사·레벨업·유물 선택을 열지 않는다.
2. **1~4스테이지 목표 달성:** 대기열 다음 조각의 생성 충돌을 검사한다. 불가능하면 생성 불가 패배, 가능하면 ‘중간 목표 달성’ 상태를 기록하고 완료 XP 10을 한 번만 지급한다. 종류 예약은 모양·특수 셀 위치를 바꾸지 않으므로 충돌 검사 결과는 성장 선택으로 바뀌지 않는다.
3. **목표 미달 + 남은 조각 0:** 목표 미달 패배.
4. **목표 미달 + 다음 조각 생성 불가:** 생성 불가 패배.
5. 계속할 수 있으면 현재 경험치로 가능한 레벨업 선택을 한 번씩 처리한다. 앞선 선택을 반영해 다음 후보를 새로 만든다.
6. 중간 목표 달성 상태라면 레벨업을 모두 마친 뒤 유물 선택을 처리하고 다음 스테이지의 점수·조각 수를 초기화한다.
7. 대기열을 유지한 채 다음 조각을 생성한다.

- 마지막 조각으로 목표를 달성해도 성공할 수 있다.
- 실패가 확정되면 레벨업으로 구조하지 않는다. 이번 강화 후보에는 즉시 보드 제거·추가 조각 지급이 없다.
- 여러 레벨업과 스테이지 보상이 겹치면 **연쇄 종료 → 종료 판정 → 레벨업 선택들 → 유물 선택 → 다음 조각**이다.
- 승리·패배 시 미처리 레벨업 선택은 종료하며 빌드를 다음 판으로 넘기지 않는다.

### 9.4. 결과 기록

종료 화면에 승리·패배, 도달 스테이지, 총점, 실제 배치 조각 수, 최대 한 배치 폭탄 수, 최대 한 배치 묶음 수, 플레이 시간, 도달 플레이어 레벨, 최종 폭탄 종류·레벨, 획득 유물을 표시한다.

최고 기록은 아래 순서로 비교한다.

1. 승리 기록 우선.
2. 패배끼리는 도달 스테이지가 높은 기록 우선.
3. 같은 승패·스테이지면 총점이 높은 기록 우선.
4. 같으면 배치 조각 수가 적은 기록 우선.
5. 모두 같으면 기존 기록 유지.

플레이 시간은 참고 정보다. 게임 중 자동 낙하·고정 대기·폭발·중력 시간을 포함하고, 일시정지·규칙 안내·레벨업·유물 선택 시간은 제외한다. 빠른 연출 옵션으로 기록 경쟁을 유도하지 않으며 온라인 순위표는 없다.

## 10. 판 안의 성장과 보조 유물

### 10.1. 경험치와 플레이어 레벨

- 새 판은 플레이어 Lv.1, 경험치 0으로 시작한다.
- N 하나당 1 XP와 진행 가능한 중간 스테이지 완료당 10 XP를 얻는다. 점수 배율과 경험치를 분리한다.
- 현재 플레이어 레벨 L에서 다음 레벨까지 필요한 경험치는 **8 + 4×(L-1)**이다.
- 필요량은 Lv.1→2에 8, Lv.2→3에 12, 이후 16·20·24…로 증가한다.
- 필요 경험치를 소비하고 초과분을 남긴다. 스테이지를 넘겨도 남은 경험치는 유지한다.
- 레벨업은 현재 배치가 끝나고 계속 진행할 수 있을 때만 선택 화면으로 처리한다.
- 연쇄 한 번으로 여러 레벨업이 가능하면 하나씩 고르고, 선택마다 경험치를 소비하고 플레이어 레벨을 1 올린다.
- 완료 보너스를 제외한 XP 계산 예: Lv.1·0 XP에 N 파괴 XP 20을 넣으면 선택 2회 후 Lv.3·0 XP다. 진행 가능한 중간 목표도 달성했다면 완료 XP 10을 더해 Lv.3·10 XP가 된다.
- 플레이어 레벨은 성장 선택 횟수다. 별도의 자동 공격력·점수 배율을 주지 않는다.
- 경험치 곡선과 완료 XP는 첫 시험값이다. 성공한 한 판에서 레벨업 선택 약 6~8회와 유물 선택 4회를 내부 조정 목표로 삼는다. 강한 빌드가 완성되는지와 선택 대기를 실제 측정하며, 이 횟수를 재미의 증명이나 플레이어별 보장으로 쓰지 않는다.
- 원래 곡선에서 3종을 모두 Lv.3으로 만들려면 신규 획득 2회+강화 6회=8회, 누적 176 XP가 필요하다. 모든 판에서 최대 빌드 완성을 요구하지 않는다.

### 10.2. 레벨업 후보와 효과

레벨업에서는 **폭탄 성장 최대 2개 + 공통 강화 최소 1개**, 총 3개를 제시하고 1개를 고른다. 새 종류를 원하지 않을 때도 현재 구성을 유지하며 성장할 수 있어야 한다.

| 행동 | 후보 자격 | 선택 효과 |
|---|---|---|
| 신규 폭탄 획득 | 미보유 종류이며 보유 슬롯이 3종 미만 | 해당 종류 Lv.1 획득, 첫 등장 예약·이후 종류 Bag 편입 |
| 보유 폭탄 강화 | 보유한 종류의 레벨이 3 미만 | 해당 종류 레벨 +1 |

- 각 종류의 현재 가능한 행동을 하나만 만든다. 미보유 획득과 해당 종류 강화가 동시에 나오지 않는다.
- 시작 핵심 후보는 기본 강화와 가로·세로·중계 획득의 4개다.
- 핵심 후보가 2개 이상이면 균등하게 2개를 추첨한다. 1개면 그 1개, 0개면 없음이다.
- 나머지는 공통 강화 3종 가운데 서로 다르게 추첨해 채운다. 핵심 후보가 3개 남아 있어도 신규 폭탄 획득만 강요하지 않는다.
- 기본도 보유 슬롯 하나를 사용한다. 3종이면 신규 획득 후보를 제외한다. 강화 상한은 종류별 Lv.3이다.
- 폭탄 교체·판매·되돌리기·새로고침·선택 보류는 없다. 획득 전에 종류별 현재/예상 비중, 현재→다음 범위, 중계와 파괴의 차이를 보여 준다.
- 신규 종류의 전환 비용과 낮은 레벨은 실제 선택 정보다. 다음 판에서 영구 해금으로 보상하지 않는다.
- 강화는 보드와 대기열의 같은 종류에 적용하되 이미 끝난 배치 점수·XP는 다시 계산하지 않는다.

### 10.3. 공통 강화

각 레벨업에 최소 1개를 제시한다. 핵심 후보가 1개면 공통 2개, 0개면 공통 3개다. 같은 화면에서 같은 공통 강화를 중복 표시하지 않는다.

| 공통 강화 | 1회 효과 | 누적 |
|---|---|---|
| 회수 숙련 | 파괴한 N의 기본 단가 +1점 | 가능 |
| 낙하 숙련 | 추가 폭발 묶음당 보너스 +5점 | 가능 |
| 폭탄 숙련 | 발동 B 하나당 배치 점수 +5점 | 가능 |

이들은 현재 폭탄 구성을 유지할 선택과 최고레벨 이후의 성장을 제공한다. 경험치 획득량·조각 공급·남은 조각 수·폭발 범위를 바꾸지 않는다. 획득 횟수는 판 안에서만 누적하고 새 판에서 0으로 초기화한다.

### 10.4. 스테이지 보상: 보조 유물 6종

이전 합의의 유물 6종·5스테이지는 유지한다. **폭탄 획득·종류별 강화가 주 성장이고, 유물은 플레이 방식을 보조한다.**

- 1~4스테이지 완료 때 미보유 유물 중 3종을 균등 추첨해 1개를 고른다.
- 처음부터 6종 모두 후보에 넣는다. 판 밖 해금·희귀도·가격·성능 강화는 없다.
- 중복 획득·교체·판매·새로고침·보상 건너뛰기는 없다.
- 선택 전 미보유 수는 6→5→4→3이므로 4번 모두 3종을 제시한다.
- 최종 보유 유물은 4개이고 새 판에서 모두 사라진다.

| ID | 유물 | 정확한 효과 |
|---|---|---|
| R01 | 정밀 폭파 | 파괴한 N의 기본 단가 +2점 |
| R02 | 연쇄 증폭기 | b≥2이면 기본 폭탄 수 배율에 +0.5 |
| R03 | 점화 증폭기 | 최초·후속 검사 모두 대각선 T–B 접촉도 점화 |
| R04 | 낙하 충전기 | 추가 폭발 묶음당 점수 +30점 |
| R05 | 폭파 보너스 | 한 배치 N 10개 이상 파괴 시 +75점 1회 |
| R06 | 내열 트리거 | T가 폭발로 파괴되지 않음. 점유·중력은 유지 |

기존 R01 고폭 화약은 모든 B를 같은 5×3으로 바꾸어 종류별 특징과 충돌하므로 정밀 폭파로 대체한다. 범위 성장은 각 폭탄의 레벨에서 담당한다.

### 10.5. 상호작용과 빌드 예시

- 다른 종류끼리 파괴 범위에 들어가면 같은 묶음으로 전달된다. 중계 폭탄은 별도 중계 범위에서도 B를 발동시킨다.
- 같은 묶음에서 전부 터지면 폭탄 수 배율은 받지만 중력 후 추가 묶음 보너스는 없다.
- 가로 폭탄으로 연결하면서 기존 T를 먼저 지워 후속 연쇄를 잃을 수도 있다.
- 내열 T는 획득 전·후 T에 모두 적용하고 살아남은 T도 아래로 낙하한다.
- 점화 증폭기는 T–B 접촉 조건만 바꾼다. 파괴·중계 범위나 중계 방향은 바꾸지 않는다.

| 방향 | 구성 예시 | 노리는 선택 |
|---|---|---|
| 수평 연결 | 기본+가로 / 연쇄 증폭기 | 먼 B를 한 묶음으로 연결 |
| 낙하 재점화 | 기본+세로 / 낙하 충전기·내열 T | 같은 열을 비워 낙하 후 접촉 |
| 중계 연결 | 기본+중계 / 연쇄 증폭기 | 중간 N/T를 보존하며 먼 B 점화 |
| 광역 정리 | 기본 폭탄 강화 / 폭파 보너스 | 한 배치의 N 파괴량 증가 |

예시는 설계 의도이며 강한 조합·균형·반복성이 검증되었다는 뜻은 아니다. 새 판의 시작 성능은 항상 같고 이전 판의 획득·레벨·숙련·유물·경험치는 승계하지 않는다.

### 11.2. 배치 전 예고

- 고스트 네 칸과 B/T 위치를 표시한다.
- 그 착지로 **즉시 점화되는 첫 묶음 전체**의 B와 실제 파괴 범위를 얇은 테두리로 표시한다. 중계 연결은 별도 점선으로 보여 주며 점선을 파괴 영역처럼 칠하지 않는다.
- 첫 접촉 B뿐 아니라 폭발·중계로 전달될 B까지 각 종류·현재 레벨의 규칙으로 계산한다. 파괴 집합과 점화 연결을 별도로 얻는다.
- 보드·고스트·다음 조각에서 B01/B02/B03/B04를 심볼로 구분한다. 종류별 레벨은 보유 목록과 선택 화면에서 읽을 수 있어야 한다.
- 내열 T는 예고 범위 안이어도 파괴 대상으로 표시하지 않는다.
- 중력 이후의 모든 결과·최종 점수·최적 배치는 예고하지 않는다.
- 예고는 판정과 같은 규칙 데이터를 사용한다. 보이는 범위와 실제 범위가 달라서는 안 된다.
- 고스트가 현재 조각과 겹치더라도 특수 셀과 착지 위치를 읽을 수 있어야 한다.

### 11.3. 폭발 중·배치 후 정보

- 묶음이 시작할 때 ‘1차 폭발’, ‘2차 폭발’처럼 묶음 번호를 표시한다.
- 같은 묶음의 폭탄 전달은 공간적인 연결로 보여 주되 중력이 일어나는 것처럼 표현하지 않는다.
- 폭탄 수와 묶음 수를 구분한다. ‘폭탄 4개 / 중력 후 재점화 1회’와 같이 원인을 읽게 한다.
- 종료 시 파괴 점수·배율·중력 및 성장 보너스를 짧게 합산하고 획득 XP를 별도로 표시한다. 경험치가 점수 배율만큼 증가하는 것처럼 표현하지 않는다.
- 상단 위험 구간은 y=14~17의 4행이다. 고정 셀이 있으면 경고 테두리를 표시한다. 이 선 자체는 패배 조건이 아니다.
- 점수가 적거나 0점인 배치도 부정적인 경고음을 반복하지 않는다. 준비 배치가 실패처럼 느껴지게 하지 않는다.

### 11.4. 가독성과 아트

- 보드는 어두운 중립 배경, 셀은 명확한 테두리를 사용한다.
- N은 단색 사각형, T는 점화 심볼로 표시한다. B는 기본 원형·가로 화살표·세로 화살표·중계 안테나로 구분한다. 색상만으로 종류를 식별하게 하지 않는다.
- 조각 형태별 색상 7개를 암기하게 하지 않는다. **셀 역할을 우선**해 읽도록 한다.
- 내열 T에는 방패 테두리를 추가한다.
- 폭탄 종류 아이콘 4개와 보조 유물 아이콘 6개를 도형·심볼 위주로 제작한다. 중계 폭탄은 점선 연결과 3×3 파괴 영역이 구분되어야 한다. 강화 단계별로 다른 그림을 대량 제작하지 않는다. 캐릭터·맵·장면별 배경을 만들지 않는다.
- UI는 16:9를 기준으로 설계하고 16:10·울트라와이드에서는 보드 비율을 유지한 채 여백을 확장한다.
- 최소 대응 해상도는 1280×720이다. 확대·전체 화면에서도 설명·버튼·보드가 잘리지 않아야 한다.

## 12. 연출과 사운드

### 12.1. 기본 연출

| 단계 | 기본 목표 시간 | 표현 |
|---|---:|---|
| 조각 고정 | 0.06초 | 테두리 강조 |
| 묶음 발동 | 0.12초 | 발동 B·연결 강조 |
| 셀 제거 | 0.12초 | 짧은 파티클·셀 소멸 |
| 중력 이동 | 0.16초 | 계산된 좌표로 동시 이동 |
| 착지·다음 검사 표시 | 0.05초 | 작은 착지 피드백 |
| 배치 점수 합산 | 0.20초 | 구성 점수와 총합 |

- 한 묶음의 폭탄 수만큼 대기 시간을 선형으로 늘리지 않는다.
- 같은 묶음의 연결은 짧은 시각 차이로 보여 주고 판정은 동시에 처리한다.
- 연출은 판정 결과를 재생하며, 파티클·물리 충돌로 게임 결과를 결정하지 않는다.
- 설정의 **빠른 연출**은 위 시간에 0.5를 곱한다. 낙하 조작 속도·고정 시간·점수·시드는 바꾸지 않는다.
- 폭발이 없으면 불필요한 중력·점수 연출 없이 고정 피드백 뒤 다음 조각으로 넘어간다.
- 효과를 줄여도 점화 위치·묶음 번호·파괴 범위는 유지한다.

### 12.2. 사운드

필수 효과음은 이동, 회전, 고정, 폭탄 발동, 묶음 상승, 목표 달성, 레벨업·유물 획득, 승리·패배, 메뉴 확인·취소다. 음악은 루프 1곡으로 시작한다.

같은 묶음의 폭탄마다 큰 소리를 겹쳐 틀지 않는다. 묶음 상승은 음높이·짧은 강조음으로 표현하되 과도한 음량 상승을 피한다. 옵션은 마스터·음악·효과음 음량을 각각 제공한다.

### 12.3. 설정 확정 범위

- 창 모드 / 테두리 없는 전체 화면.
- 창 모드 해상도: 1280×720, 1600×900, 1920×1080 중 화면에 맞는 항목.
- 화면 흔들림: 기본 켜짐, 끄기 가능.
- 강한 번쩍임: 기본 약하게, 끄기 가능.
- 연출 속도: 기본 / 빠르게.
- 마스터·음악·효과음 음량: 각각 0~100.
- 조작 재지정은 첫 완성판에서 제외하고 6장의 기본 구성을 사용한다.

## 13. 규칙 안내·저장·중단

### 13.1. 게임 방법

최초 새 게임에서 아래 네 장의 짧은 안내를 보여 준다. 자동 낙하는 시작하지 않으며, 확인 후 빈 보드의 1스테이지를 시작한다. 이후에는 메뉴에서 다시 볼 수 있다.

1. **쌓기:** 이동·회전·드롭, B/T 식별, 줄을 채워도 지워지지 않음.
2. **터뜨리기:** 고정 후 B–T 접촉, 3×3 기본 범위, 다른 B로 전달.
3. **이어 터뜨리기:** 폭발 후 모든 열의 셀별 낙하, 중력 후 재접촉, 목표 점수와 조각 제한, 보드 계승.
4. **빌드 만들기:** N 파괴와 중간 완료→XP→3택1, 신규/종류별 강화/공통 강화, 중계와 파괴의 차이, 첫 등장 예약, 판 종료 시 초기화.

각 장은 도식 1개와 핵심 문장 위주로 구성한다. 별도 연습 모드·긴 튜토리얼 스테이지는 만들지 않는다. 신규 폭탄·강화·유물 효과는 선택 화면에서 정확히 설명한다.

### 13.2. 로컬 저장

저장 대상은 **설정, 최초 안내 확인 여부, 최고 기록 1개, 누적 플레이·승리 횟수**다.

- 설정은 적용 시 저장한다.
- 완료된 판의 기록은 결과 화면 진입 시 저장한다.
- 진행 중인 보드·시드·남은 조각·경험치·플레이어 레벨·폭탄 보유·종류별 레벨·숙련·유물은 이어하기 데이터로 저장하지 않는다.
- 완료 기록에 최종 빌드를 남길 수 있으나 조회 정보일 뿐 다음 판의 후보·성능·레벨에 영향을 주지 않는다. 해금 목록·영구 재화·영구 강화 저장 항목은 없다.
- 저장 형식에는 버전 번호를 두고, 읽기 실패 시 기본값으로 시작한다.
- 저장 실패로 현재 플레이를 막지 않는다. 사용자에게 기록 저장 실패를 짧게 알린다.
- 게임 판정과 저장 로직을 결합하지 않는다.
- Steam 계정별 동기화·클라우드·온라인 기록은 범위 밖이다.

### 13.3. 일시정지와 포기

- 포커스 상실·컨트롤러 해제·일시정지 입력은 판을 보존한 채 멈춘다.
- 진행 중 ‘메뉴로 돌아가기’와 ‘다시 시작’에는 **현재 판이 저장되지 않음**을 알리는 확인창을 띄운다.
- 앱 종료 후 이어하기는 제공하지 않는다.
- 일시정지·설정·레벨업·유물 화면을 오래 열어 두어도 시간 때문에 패배하지 않는다.

## 14. 판정 확인용 연쇄 예시

다음은 프로그래머와 기획자가 같은 결과를 기대하도록 고정한 예시다. 별도 튜토리얼 맵을 추가하라는 뜻은 아니다.

14.1~14.4의 점수·XP는 배치 판정 자체의 값이다. 스테이지 목표까지 달성했다면 9.3의 종료 판정과 완료 XP를 별도로 적용한다.

### 14.1. 시작 보드와 배치

아래는 보드 하단 5행이며 표시하지 않은 위쪽은 전부 빈칸이다.

```text
y=4  ....B.....
y=3  ....N.....
y=2  ....N.....
y=1  ...BNT....
y=0  .NNNNN....
     0123456789
```

- 아래 폭탄 B₁=(3,1), 위 폭탄 B₂=(4,4). 두 셀 모두 B01이다. 별도 표기가 없으면 B01 Lv.1·유물/숙련 없음이다.
- 기존 트리거 T₂=(5,1).
- O 조각을 x=1~2, y=1~2에 고정한다.
- 조각의 (2,1)이 T이고 나머지 (1,1), (1,2), (2,2)는 N이다.
- O는 (1,0), (2,0)의 N 위에 합법적으로 착지한다.

### 14.2. 기본 폭탄 Lv.1·강화 없는 결과

1. 새 T=(2,1)이 B₁에 접촉한다.
2. B₁의 첫 3×3 폭발로 N 6개·B₁·새 T가 제거된다.
3. (4,3)의 N과 B₂가 내려와 각각 (4,0), (4,1)에 놓인다.
4. B₂=(4,1)이 기존 T₂=(5,1)에 접촉해 두 번째 묶음이 발생한다.
5. 두 번째 묶음에서 N 2개·B₂·T₂가 제거된다.
6. 최종 보드는 (1,0), (1,1), (1,2)의 N 3개만 남는다.
7. n=8, b=2, w=2이므로 **8×10×1.5+30=150점**, 경험치 **8 XP**다. 살아서 계속 진행하는 Lv.1·0 XP라면 레벨업 선택 1회를 연다.

### 14.3. 폭탄 레벨·유물에 따른 다른 결과

| 성장 상태 | 기대 결과 |
|---|---|
| B01 Lv.2, 유물/숙련 없음 | 거리 2의 오른쪽 끝점이 T₂를 제거. B₂는 낙하 후 점화되지 않음. n=7, b=1, w=1, **70점 / 7 XP** |
| B01 Lv.1 + 정밀 폭파 | n=8, b=2, w=2. 8×12×1.5+30=**174점 / 8 XP** |
| 내열 트리거만 | 두 묶음은 유지. T 2개가 남아 각각 (2,0), (5,0)에 착지. **150점** |
| 연쇄 증폭기+낙하 충전기+폭파 보너스 | n=8이어서 폭파 보너스 미발동. 8×10×2.0+60=**220점** |

Lv.2는 첫 묶음에서 N 7개를 지워 Lv.1의 첫 묶음 6개보다 많지만, 후속 묶음을 잃어 배치 전체 파괴량은 7개로 끝난다. Lv.1은 두 묶음 합계 8개다. 따라서 범위 증가가 항상 총 파괴량·점수 증가로 이어진다고 가정하지 않는다.

위 예시와 아래 중계 예시는 작성 중 별도 임시 격자 계산으로 대조했다. **실제 Unity 구현이 통과했다는 뜻은 아니다.**

### 14.4. 중계 선과 파괴 범위를 구분하는 예시

판정 단위 보드에 B01 Lv.1=(2,1),(6,4), B04 Lv.1=(3,1), B03 Lv.1=(6,1), T=(1,1), N=(5,1),(6,2)를 놓는다. 보유 종류는 기본·중계·세로의 3종이다. 배치 경로 전체가 아닌 입력 상태에 대한 판정 확인이다.

1. T가 (2,1)의 기본 폭탄을 점화하고, 그 범위의 (3,1) 중계 폭탄이 발동한다.
2. 중계가 같은 행·거리 3의 세로 폭탄 (6,1)을 발동시킨다. 중간 N=(5,1)은 중계 선 위라는 이유로 제거하지 않는다.
3. 세로 폭탄이 N=(6,2)를 제거하고 (6,4)의 기본 폭탄에 전달한다. 모두 같은 묶음이다.
4. 폭탄 4개와 N 1개가 제거되고, 남은 N=(5,1)은 중력으로 (5,0)에 놓인다.
5. n=1, b=4, w=1이므로 **25점 / 1 XP**다. 중계 길이를 추가 묶음이나 추가 N 파괴로 집계하지 않는다.

### 14.5. 성장·진행 경계 예시

아래는 완료 조건과 XP 처리의 단위 입력을 구분한 예시이며 실제 시드의 배치 경로를 보장하는 예시는 아니다.

- Lv.1·0 XP에 일반 셀 XP 20, 완료 XP 없음: 선택 2회, Lv.3·0 XP.
- 같은 배치로 진행 가능한 중간 목표까지 달성: 20+10 XP로 선택 2회, Lv.3·10 XP. 이후 유물 선택 1회.
- 목표 달성 후 다음 생성이 막힘: N 파괴 기록은 남지만 완료 XP·레벨업·유물 선택 없이 패배.
- 마지막 스테이지 목표 달성: 최종 점수 정산 후 승리. 완료 XP 보너스와 미처리 성장 선택을 열지 않는다.
- 기본 폭탄만 Lv.3이고 슬롯이 남아 있음: 신규 후보 중 2개+공통 강화 1개를 제시한다. 공통 강화를 골라 기본 단일 구성을 유지할 수 있다.

## 15. 구현 경계와 데이터

### 15.1. 규칙과 표현

- 보드·조각·폭탄 종류/레벨·경험치·선택 후보·점수·진행·유물 판정은 일반 C# 데이터와 함수에서 계산한다.
- Unity 오브젝트는 입력 전달, UI, 셀 표시, 효과음·연출을 담당한다.
- Rigidbody2D·충돌 이벤트·파티클의 실제 움직임으로 셀 판정을 결정하지 않는다.
- 연출 도중 데이터를 임의 수정하지 않는다. 묶음별 발동·중계 연결·파괴·이동 기록을 순서대로 재생한다. 보상 상태에서 정산을 재실행해 XP나 유물이 중복 지급되지 않게 한다.
- 첫 묶음 예고도 같은 판정 규칙을 사용하되 원본 보드는 변경하지 않는다.
- 구체적인 클래스 수와 상속 구조는 코드 설계에서 정한다. 범용 이벤트 프레임워크·대규모 데이터 편집기부터 만들지 않는다.

### 15.2. 상태와 기록

구현에서 구분할 상태는 **조각 조작 / 연쇄 처리 / 레벨업 선택 / 유물 선택 / 일시정지 / 결과**다. 한 상태에서 두 번 조각을 고정하거나 중복 점수를 지급하지 않게 한다. 일시정지 후에는 이전 상태와 남은 시간을 복원한다.

| 데이터 | 최소 보유 항목 |
|---|---|
| 보드 | 10×18 셀 종류, B이면 폭탄 종류 ID |
| 활성 조각 | 형태, 네 셀과 속성, B의 종류 ID, 방향, 원점, 낙하·고정 타이머 |
| 공급 상태 | 형태/속성/종류 Bag, 소비 위치, 다음 3개, 첫 등장 FIFO와 대기열 예약, 별도 난수 상태 |
| 배치 결과 | 묶음별 발동 B·중계 연결·제거 셀·이동 좌표, n·b·w·점수·N XP·완료 XP·정산 완료 여부 |
| 1회 플레이 | 스테이지, 점수, 남은 조각, 총점, 플레이어 레벨·경험치, 보유 폭탄·종류별 레벨, 숙련 횟수, 유물, 기록 |
| 설정·영구 기록 | 13.2의 로컬 저장 대상 |

묶음·셀 기록은 화면 재생과 오류 재현에 필요한 만큼만 둔다. 일반 셀마다 영구 식별자를 부여하거나 사용자용 리플레이 시스템을 만들 필요는 없다.

### 15.3. AI 활용

- 작은 규칙 단위의 구현·경계 사례·임시 UI·반복 작업에 우선 활용한다.
- 한 배치의 예상 보드·점수와 실제 결과를 사람이 대조한다.
- 생성된 코드의 컴파일 성공, 규칙 테스트 통과, Unity 연결, 실제 조작, 배포 빌드를 구분해 검증한다.
- 자동 배치의 고득점은 사람이 예측할 수 있거나 재미있다는 증거로 쓰지 않는다.
- AI가 제안한 추가 기능도 이 문서의 완성 범위를 넘으면 별도 동의 없이 넣지 않는다.
- 현재 요청은 기획 문서 확정이다. 코드·Scene·Prefab·Inspector·패키지·프로젝트 설정 변경은 별도 구현 작업이다.

| 성장 | 핵심 후보 0/1/2/3/4개 | 핵심 최대 2개, 공통 최소 1개, 합계 3개 |

| 성장 | 같은 배치 레벨업 여러 회 | 앞선 선택 반영 후 다음 후보 계산 |
| 공급 | 신규 획득·미리 보기 B 유/무·동시 2종 획득 | 모양·B/T·위치 유지, 첫 B 예약, 기존 예약 덮어쓰기 없음 |
| 강화 | 기존 종류 레벨 상승 | 해당 판의 보드·활성·미리 보기 성능 갱신, 즉시 폭발 없음 |
| 초기화 | 강한 빌드로 종료 후 새 게임 | B01 Lv.1, 플레이어 Lv.1·0 XP, 숙련/유물 없음 |
| 점수 | 이전 묶음 좌표에 다른 N 착지 후 파괴 | 새 N의 점수 누락 없음 |
| 진행 | 마지막 조각 목표 달성 | 9.3 순서 적용 |
| 진행 | 최종 목표 달성·다음 생성 충돌 | 최종 승리 우선 |
| 진행 | 중간 목표 달성·다음 생성 충돌 | 보상 화면 이전 생성 불가 패배 |
| 계승 | 스테이지·유물 선택 전후 | 보드·공급 유지, 점수·조각만 초기화 |
| 유물 선택 | 4번 연속 획득 | 항상 다른 미보유 후보 3개, 최종 보유 4종 |
| 중단 | 포커스 상실·패드 해제 | 자동 낙하·고정·연출 정지 |
| 저장 | 파일 없음·읽기/쓰기 실패 | 기본값 또는 실패 안내, 현재 판 진행 가능 |

### 16.2. 플레이 관찰

개발자 외 처음 접하는 이용자에게 실제 조작을 맡기고 다음을 확인한다. 인원수나 한 번의 호평을 시장성 증명으로 쓰지 않는다.

1. 줄이 지워지지 않는 규칙과 B/T 역할을 짧은 안내로 이해하는가.
2. 결과 전에 적어도 다음 폭발·낙하의 원인을 설명할 수 있는가.
3. 즉시 점화와 모으기를 상황에 따라 다르게 선택하는가.
4. 패배 후 고칠 수 있는 배치가 보이고, 자발적으로 다시 시작하는가.
5. 새 폭탄 획득·강화·유물 선택 이유가 실제 배치에 나타나는가. 특정 종류 하나만 계속 고르는 것이 정답은 아닌가.
6. 키보드와 컨트롤러 모두 원하는 배치를 실행할 수 있는가.
7. 5스테이지가 목표 플레이 길이에 들어오고 반복 입력·연출 대기가 지루하지 않은가.

### 16.3. 기록과 조정 순서

기록은 시드, 조각/종류 순서, 배치 좌표·방향, 폭탄별 레벨, 플레이어 레벨·N XP·완료 XP, 제시/선택한 성장, 신규 획득→첫 사용까지 배치 수, 숙련·유물, n·b·w, 점수, 최대 높이, 남은 조각, 종료 이유, 조작 시간·연출 시간·선택 시간이다. 정량 기록과 플레이어가 설명한 이유를 함께 본다.

| 문제 | 먼저 조정할 항목 |
|---|---|
| 초반에 무엇을 해야 할지 모름 | 안내·고스트·첫 묶음 예고·B/T 심볼 |
| 손이 늦어서 의도한 배치를 못 함 | 낙하·고정 지연·입력 반복·회전 보정 |
| 배치는 이해하지만 목표 점수에 일관되게 못 미침 | 스테이지 목표 점수 |
| 공급 공백에 반복적으로 대응이 막힘 | 같은 시드의 당시 정보로 대안 검토 후 속성 Bag |
| 폭발 범위가 퍼즐을 지나치게 지움 | 해당 폭탄의 종류별 레벨 범위와 등장 빈도 |
| 성장이 너무 느리거나 선택 화면이 잦음 | XP 필요량과 선택 소요 시간. 영구 강화로 해결하지 않음 |
| 특정 폭탄만 강화하는 것이 정답 | 종류별 제거량·연결 거리·레벨 성장 폭 |
| 유물 하나가 대부분 상황에서 지배적 | 해당 효과 수치·조건 |
| 즉시 점화 또는 무조건 적층만 정답 | 기본 배율·묶음 보너스·점수 목표 |
| 1회 플레이가 너무 김 | 목표·조각 수·연출 길이. 모드 추가로 해결하지 않음 |

같은 문제를 한 번에 여러 설정을 바꿔 가며 조정하지 않는다. 수치로 해결되지 않아 점화 방식·보드 계승·새 기능이 필요해지면 기획 변경 사유를 정리하고 사용자와 결정한다.

**중단 기준:** 기본 플레이를 수정한 뒤에도 의도적인 연쇄와 재도전 이유가 관찰되지 않으면 콘텐츠 확대와 판매 준비를 멈추고 핵심 방향을 다시 판단한다.

### 16.4. 재미·성장 비교의 통과 기준

다음은 개발 내부의 관찰·조정 기준이다. 통계적인 흥행 기준이나 이미 달성한 결과가 아니다.

| 비교 | 조건 | 확인할 결과 |
|---|---|---|
| 기존 강화 vs 신규 획득 | 같은 형태/속성 시드·같은 선택 횟수. 기본 2회 강화와 기본 1회 강화+신규 획득을 비교 | 신규 선택을 실제로 활용해 유리해지는 보드가 있음. 새 종류가 모든 상황에서 정답일 필요는 없음 |
| 기본 편중 | 초기·중기·고적층 보드와 서로 다른 시드에서 비교 | 기본만 강화하는 선택이 거의 모든 상태를 지배하면 범위·타종 레벨·종류 비중을 재조정 |
| 중계의 역할 | 같은 보드에서 가로/세로와 중계를 비교 | 중간 N/T 보존이 이후 계획을 바꾼 사례가 있음. 효과를 설명하지 못하면 종류를 추가하지 말고 표시·규칙부터 수정 |
| XP와 목표 | 빠른 고득점 완료와 많은 N 파괴 경로를 모두 관찰 | 스테이지 완료 XP를 포함해 빌드를 고를 기회가 충분함. 잘 클리어한 판의 성장 기회가 과도하게 적지 않음 |
| 성장 빈도 | 실제 성공 판의 선택 횟수와 선택/연출/조작 시간을 분리 | 레벨업 약 6~8회·유물 4회를 첫 조정 목표로 삼되 선택 대기가 플레이를 지배하지 않음 |
| 늦은 신규 획득 | 마지막 스테이지 중 획득과 미리 보기 경계를 확인 | 첫 등장 예약을 이해하고 사용 기회가 생김. 종료 전 사용되지 않는 보상이 반복되면 제시 조건·XP 곡선을 조정 |

- 같은 착지의 결과만 비교하면 파괴 차이는 확인할 수 있지만 빌드의 강함은 확정할 수 없다. 각 빌드에 맞춘 다른 배치도 허용해 비교한다.
- 점수·클리어율뿐 아니라 최대 높이·필요 조각·폭탄/묶음 수·새 종류 실제 사용·선택 이유를 함께 본다.
- 종류별 범위, XP 곡선, 목표 점수는 독립적으로 조정한다. 한 번의 결과로 모두 바꾸지 않는다.
- 기본 폭탄·중계·신규 획득에 문제가 남으면 5번째 폭탄, 분열, 지연, 상태이상을 추가해 덮지 않는다.
- 스테이지가 점수 차이만으로 반복된다는 위험은 남는다. 2스테이지 실플레이에서 성장과 배치 변화가 충분한지 먼저 확인하고 새 스테이지 기믹은 별도 결정한다.

## 17. 단계별 개발과 첫 완성판 검수

### 17.1. 개발 순서

| 단계 | 작업 | 완료 조건 |
|---|---|---|
| A. 판정 | 격자·고정·접촉·전달·제거·중력·점수 | 14장 예시와 주요 경계 사례가 맞음 |
| B. 기본 한 판 | 7종 조작·Bag·다음 3개·고스트·첫 묶음 예고·실패·재시작 | 유물 없이 배치를 계획하고 직접 조작할 수 있음 |
| C. 폭탄 빌드 | 폭탄 4종·중계·레벨·XP·핵심2+공통1·종류 Bag·첫 등장 예약 | 신규 획득/강화/공통 유지가 실제 배치 선택을 바꿈 |
| D. 짧은 진행 | 2스테이지·빌드/보드 계승·보조 유물 선택 1회 | 성장 선택과 스테이지 보상의 순서가 맞음 |
| E. 전체 진행 | 5스테이지·레벨업·유물 선택 4회·최고 기록 | 승리·패배·다시 시작까지 한 판이 완결됨 |
| F. 마감 | 안내·설정·저장·양 입력 장치·아트·사운드·배포 검수 | 아래 검수 목록 통과 |

D단계는 개발 중 확인을 위해 2스테이지 뒤 종료시킬 수 있다. 최종 모드의 종료 지점은 5스테이지이며, 별도 2스테이지 모드나 선택 UI는 만들지 않는다.

첫 구성은 폭탄 4종·종류별 3레벨·판내 최대 보유 3종·보조 유물 6종이다. 순서는 A→F로 진행하고, 폭탄 성장의 재미를 확인하기 전에 판 밖 경제·새 모드를 추가하지 않는다. 고정 일정은 약속하지 않는다.

### 17.2. 제품 범위

- Windows 64비트 빌드.
- 한국어·영어 UI와 게임 방법. 문구는 분리하여 관리하고 의미·버튼 안내를 검토한다.
- 키보드와 컨트롤러로 시작·설정·플레이·레벨업·유물 선택·결과·재시작·종료까지 진행.
- 컨트롤러 검수는 실제 보유한 Windows 대응 패드로 수행하고, 확인하지 않은 기기의 호환성을 광고하지 않는다.
- 메뉴·폭탄 성장·유물 설명은 D패드 초점만으로 읽고 선택할 수 있어야 한다. 마우스를 필수로 요구하지 않는다.
- 목표 성능은 1920×1080에서 안정적인 60fps. 최소 사양은 실제 배포 빌드 측정 뒤 작성하며 현재 하드웨어 성능을 추정해 기재하지 않는다.

### 17.4. 판매 준비의 남은 결정

실제 체험 반응을 확인한 뒤 출시 정가·상점 캡슐·트레일러·최소 사양·공개 일정을 정한다. 기본 구매 이유는 ‘연쇄를 직접 설계하는 짧은 퍼즐’로 통일한다. 콘텐츠 양이나 예상 판매량을 근거 없이 크게 약속하지 않는다.

판매 페이지 작성·업로드·공개·빌드 배포는 이후 사용자가 요청한 작업에서 진행한다.

## 18. 검토 반영 결정과 남은 검증

### 18.1. 사용자 확인 사항

- 낮은 시간 압박의 조작·배치 퍼즐, 폭발 후 셀별 낙하와 재점화를 유지한다. 별도 지지대는 없다.
- 여러 폭탄과 종류별 성장으로 매 판 빌드를 만든다.
- 경험치·레벨업마다 3개 중 선택하고, 영구 해금·판 밖 재화·누적 성능 강화는 사용하지 않는다.
- 후반에는 확실히 강해지되 계획해서 큰 연쇄를 만드는 경험을 남긴다.
- 범위 차이에 소수의 독특한 작동 방식을 더한다.
- Steam·Windows·키보드와 컨트롤러·5스테이지·보조 유물 6종을 유지한다.
- AI를 적극 활용해 작은 범위를 완성하며 별도 개발 기한은 없다.

| 확인한 문제·위험 | v1.2 보완 | 한계 |
|---|---|---|
| 기본 9→15→25칸 성장과 신규 Lv.1 공급 희석 | 기본 9→13→17칸, 선택 정보에 비중·실제 레벨 표시, 같은 투자 비교 추가 | 신규 획득이 항상 유리하다고 보장하지 않음 |
| 기본만 최고레벨일 때 신규 획득 강제 | 핵심 최대 2개+공통 최소 1개 | 공통 숫자 강화가 지나치게 우세한지도 확인 필요 |
| 기존 대기열·종류 Bag 때문에 신규 체감 지연 | 다음 B에 공개된 첫 등장 예약 | 종료가 먼저 오면 실제 사용은 보장 못 함 |
| 점수 목표 달성이 성장 기회를 줄일 수 있음 | N XP 외 중간 완료당 10 XP, 성공 판 성장 횟수 측정 | 곡선·목표의 적정성은 실측 전 |
| 4종이 범위 차이뿐임 | 십자 후보를 중계 폭탄으로 교체, 파괴와 점화를 분리 | 예고 가독성과 전술 가치를 실플레이 확인 |
| 판정 예시가 기존 범위에 묶임 | 새 Lv.2 결과 70점/7 XP와 중계 예시 추가 | 임시 격자 대조이며 Unity 검증 아님 |

폭탄 4종·종류별 3레벨·보유 3종, 범위와 중계 거리, 8·12·16… XP 곡선, 완료 XP 10, 성장 6~8회 목표는 위 방향을 위한 **초기 설계값**이다. 사용자가 각 숫자와 규칙을 개별 확정한 것처럼 기록하지 않는다.

### 18.3. 현재 결론과 한계

핵심 규칙과 성장 선택을 비교할 최소 프로토타입은 설계할 수 있다. 그러나 기본 폭탄 편중, 종류 희석, XP와 점수의 관계, 중계의 가독성, 후반 난도·반복성을 검증하기 전에는 유료 게임의 재미가 확보됐다고 판단할 수 없다.

이번 검토는 기획서 전체의 정합성·수학적 경계·격자 예시를 확인한 것이다. 실제 플레이, Unity 컴파일·연결, 컨트롤러·배포 빌드, 시장 수요는 검증하지 않았다. 코드·Scene·Prefab·설정·패키지는 변경하지 않았다.
